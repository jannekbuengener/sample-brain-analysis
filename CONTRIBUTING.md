# Contributing

Keep changes within the database-free Analysis package boundary. Start with a
failing focused behavioral test for a behavior change, preserve frozen
expectations, then run all gates from [PROJECT_META.yaml](PROJECT_META.yaml).
Do not include private audio or evaluation artifacts. Changes to the public
manifest require an explicit contract update and corresponding tests.

Pull requests must fill in the repository template, identify exclusions, list
only checks that actually ran, and state remaining uncertainty. No reviewer or
approval workflow is implied by this file.

The repository currently has no license file copied from the Sample Brain
source. Do not add license terms without an explicit rights decision.
